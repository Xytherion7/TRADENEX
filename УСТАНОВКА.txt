TRADENEX 0.4.0 — ДЛЯ ПОЛЬЗОВАТЕЛЯ

Релизный вариант должен поставляться одним файлом: TRADENEX-Setup-x64.exe.

Пользователь запускает этот установщик один раз. Он устанавливает приложение, создаёт ярлык и деинсталлятор. Node.js, Rust, Visual Studio, C++ Build Tools, npm и .bat-файлы пользователю не требуются.

Установщик использует Tauri WebView2 downloadBootstrapper: если Microsoft WebView2 Runtime отсутствует, запускается bootstrapper; если runtime уже есть, повторная установка не требуется. Windows 11 обычно включает Evergreen WebView2 Runtime.

ВАЖНО: приложенный архив — это исходный код, не готовый EXE. Сначала Windows workflow должен успешно собрать TRADENEX-Setup-x64.exe.

Крипто-данные — публичные Binance market data, без биржевого логина/пароля. Акции загружаются через Twelve Data после добавления API key в Settings. В этой версии ключ хранится локально в профиле WebView; Windows Credential Manager ещё не подключён.

TRADENEX — исследовательское и учебное приложение. Оно не отправляет ордера, не подключает брокерские счета и не использует кредитное плечо.
